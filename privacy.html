Privacy policy

Prepared for setup review on September 21, 2026.

This policy describes BIG BOT Backups, a private backup tool run on its owner's computer. The owner is its sole intended user and operator. This site provides information only; it does not connect a Google Account or receive backup files.

Google access and data used

When connected by the owner, the tool requests https://www.googleapis.com/auth/drive.file. The backup workflow creates and accesses its own Drive files and folders. It uses their identifiers, names, sizes, timestamps, and available integrity information to upload, locate, download, and verify recovery snapshots. It also reads storage quota information to avoid exceeding available space.

The tool receives OAuth authorization tokens so it can perform these operations after consent. It does not request Gmail, Contacts, Calendar, or unrestricted Drive permissions. Google handles account sign-in; the tool does not receive the owner's Google password.

Purpose and Limited Use

Google user data is used only to provide the owner-authorized backup, verification, and recovery functions described on this site. BIG BOT Backups follows the Google API Services User Data Policy, including its Limited Use requirements. Google user data is not sold, shared for advertising, used for profiling, or used to train general-purpose AI models.

Storage and credential protection

The implemented backup design encrypts archive contents and backup names locally with rclone crypt before transferring them to Google Drive over encrypted network connections. Google still processes account and service metadata, such as stored file sizes, timestamps, and network activity. The owner retains the encryption password separately for recovery.

OAuth tokens and backup encryption settings are stored in an encrypted rclone configuration on the owner's computer, with restricted Windows file permissions. The host setup stores the configuration-unlock password using Windows Data Protection API (DPAPI), bound to the Windows user and computer. These protections require completing the local setup; this policy does not assert that setup or a recovery test has already succeeded.

Local recovery files and verification records can contain decrypted backup data. The owner is responsible for securing the computer and any recovery copies. Credential files are excluded from the backup package.

Sharing and service providers

Encrypted snapshots are sent to the Google Drive account selected and authorized by the owner. The backup workflow does not publish snapshots, create public sharing links, or send Google user data to advertisers, data brokers, or an AI service. The owner can read their own recovered files.

Google operates the storage and authorization services under the Google Privacy Policy. The information site may be hosted separately from the backup system; its hosting provider may process ordinary connection logs.

Retention, deletion, and revocation

Remote snapshots are retained until the owner deletes them or Google applies its account or storage policies. The backup routine creates separate snapshots without overwriting earlier ones and does not automatically delete remote backups. Reaching a configured storage or snapshot limit stops new backups instead of deleting older copies.

The owner can delete snapshots in Google Drive and manage its trash, remove local recovery files and verification records, and remove the local credential configuration. Local files remain until removed by the owner or the local system's explicitly configured cleanup. Deleting a remote snapshot does not remove downloaded local copies.

Access can be revoked in Google Account connections. Revocation prevents future authorized Drive operations but does not erase existing Drive files, local copies, or records. Google provides instructions for reviewing and removing app access.

This informational site

The site's own code has no analytics, advertising, cookies, tracking scripts, forms, or external embedded resources. Following an external link takes the visitor to that provider's service and privacy practices. A hosting provider may log requests, including IP addresses and browser information.

Contact and changes

This is an owner-operated personal tool, not a service offered to the public. Its owner handles configuration, privacy decisions, and deletion through the local installation and Google Account. No public support inbox or third-party data collection channel is provided by this site.

If the tool's use of Google data changes, this policy and the local disclosures must be updated before the new use begins, and the owner must authorize any newly required access.
